# UD01_Act07_MiguelBedmar

Este proyecto está realizado por Miguel Bedmar alumno de Ilerna Sevilla actualmente cursando segundo de desarrollo de aplicaciones multimedia.

# 📋 Descripcion.
Este proyecto se encuentra desarrollado en Kotlin  de tipo consola en donde se simulara una agenda de contactos por medio de listas mutables
,menus interactivos en donde se le dara la bienvenida al usuario del sistema. eliminacion de contactos y creación.

# 🎯 Objetivo
Aprender a manipular y manejar listas mutables en kotlin y comprender como podemos almacenar un datos o varios de ellos en memoria local  manipulandolos
con una lista dinámica.
